Finance Assistant Dokumentasi

Data & Privasi

Data Kamu, Tetap di Ruangmu

Finance Assistant dibangun dengan prinsip sederhana: data keuangan adalah milik user yang membuatnya.

Karena itu, Finance Assistant tidak mengumpulkan data keuangan pengguna ke dalam satu database pusat. Pada aplikasi Android, seluruh data keuanganmu tersimpan lokal di perangkatmu sendiri.

Prinsip utama Finance Assistant

Data keuangan tinggal di perangkat milikmu. Google Drive hanya menjadi tempat cadangan dan sinkronisasi milikmu, bukan tempat aplikasi mengambil alih datamu.

Mengapa Harus Login dengan Google?

Login Google dipakai untuk menghubungkan Finance Assistant dengan Google Drive milikmu. Saat pertama kali masuk, aplikasi dapat memuat file Finance Core dari Drive tersebut, termasuk data yang sebelumnya kamu buat di Finance Assistant versi web.

Sesudah itu, login menjaga sesi kamu dan memberi aplikasi akses terbatas ke Drive, hanya untuk menyimpan dan memuat kembali file Finance Core milikmu saat kamu menjalankan sinkronisasi.

Jadi, login Google bukan untuk mengirim data keuanganmu ke server pusat. Login tersebut menjadi penghubung antara aplikasi di perangkatmu dan ruang cadangan pribadi milikmu di Google Drive.

Data Tersimpan di Perangkatmu

Semua yang kamu catat, mulai dari pemasukan, pengeluaran, tabungan, kas, payroll, airdrop, sampai konfigurasi workspace, tersimpan di penyimpanan internal aplikasi pada perangkat Android kamu.

Artinya, data tetap bisa kamu buka dan kelola dari aplikasi tanpa bergantung pada koneksi internet, dan tidak ada spreadsheet pusat yang menampung data keuangan seluruh pengguna Finance Assistant.

Setiap user memiliki ruang datanya sendiri

Ruang data utama kamu adalah perangkatmu sendiri. User lain tidak mendapatkan akses otomatis ke workspace atau data tersebut.

Sinkronisasi ke Google Drive Milikmu

Dari halaman Profile, tombol Sinkronisasi Drive menyimpan salinan datamu sebagai file Finance Core di folder Finance Assistant pada Google Drive akun yang kamu hubungkan.

Salinan itu bisa dimuat kembali kapan saja, misalnya saat kamu berganti perangkat atau ingin melanjutkan data dari versi web. File Finance Core berada di Drive milikmu dan tetap milikmu, kamu juga bisa menghapusnya sendiri dari Google Drive kapan saja.

Bagaimana dengan Data yang Kamu Masukkan?

Data yang kamu masukkan digunakan hanya untuk kebutuhan workspace kamu sendiri di perangkatmu.

Data input tersebut tidak dibuat untuk menjadi kumpulan data milik Finance Assistant yang kemudian dapat dilihat oleh pengguna lain.

Dengan arsitektur seperti ini, developer dan user lain tidak menerima salinan data keuangan yang kamu masukkan ke dalam workspace milikmu.

Iklan dan Notifikasi

Aplikasi Android Finance Assistant menampilkan iklan melalui Google AdMob. Untuk keperluan iklan tersebut, aplikasi memakai Advertising ID perangkat sesuai kebijakan Google, dan izin iklan dapat kamu kelola dari pengaturan perangkatmu.

Notifikasi hanya dipakai untuk pengingat yang kamu aktifkan sendiri, yaitu Pengingat Harian dan Reminder Airdrop. Isi notifikasi dibuat di perangkatmu dari data workspace milikmu.

Bagaimana dengan Data Login?

Informasi login Google digunakan untuk autentikasi, menjaga sesi user, dan mendapatkan akses yang diperlukan untuk menggunakan Google Drive milik user.

Data login tidak digunakan untuk kepentingan lain, tidak dimaksudkan untuk dijadikan produk data, dan tidak disebarluaskan kepada pihak lain.

Menghapus Akun dan Data

Menu Hapus Akun di Profile menghapus seluruh data Finance Assistant di perangkatmu secara permanen. Dari sana, aplikasi juga membuka halaman penghapusan akun untuk menghapus akun login web kamu.

Logout hanya mengeluarkanmu ke layar awal. Datamu di perangkat tetap tersimpan dan bisa dimuat lagi saat kamu masuk kembali.

Visi Finance Assistant

Membantu orang mengelola keuangan dengan lebih mudah, teratur, dan nyaman, tanpa menjadikan data keuangan pribadi mereka sebagai milik aplikasi.

Ringkasan

  • Data keuangan tersimpan lokal di perangkat Android milikmu, bukan di database pusat Finance Assistant.
  • Login Google diperlukan untuk menghubungkan Finance Assistant dengan Google Drive milikmu.
  • Sinkronisasi Drive menyimpan salinan data sebagai file Finance Core di folder Finance Assistant pada Drive milikmu, dan salinan itu bisa dimuat kembali kapan saja.
  • Setiap user memiliki workspace dan data masing-masing.
  • Developer maupun user lain tidak mendapatkan akses otomatis ke data workspace milikmu.
  • Informasi login digunakan untuk kebutuhan autentikasi dan akses data yang diperlukan aplikasi, bukan untuk kepentingan lain atau disebarluaskan.
Data kamu tetap milikmu.

Finance Assistant dibuat untuk membantu kamu mengelola data tersebut, bukan untuk mengambil alih data pribadi yang kamu simpan.
