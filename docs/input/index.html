Pengaturan dan Input

Setiap Workspace memiliki cara kerja dan kebutuhan yang berbeda. Karena itu, sebelum mulai mencatat data, ada baiknya kamu menentukan terlebih dahulu bagaimana Workspace tersebut akan digunakan.

Di Finance Assistant, proses ini dimulai dari Pengaturan. Setelah aturan dan konfigurasi siap, kamu bisa mulai mengisi data melalui Input. Jika suatu saat ada data yang perlu diperbaiki, Edit Input siap digunakan.

1. Setting — Tentukan cara Workspace bekerja

Pengaturan adalah langkah awal yang paling penting ketika menyiapkan sebuah Workspace.

Di bagian inilah kamu menentukan berbagai hal yang akan menjadi dasar cara kerja Workspace, mulai dari aturan, pilihan, kondisi, hingga periode yang akan digunakan.

Dengan pengaturan yang tepat, data yang nantinya kamu masukkan tidak hanya tersimpan, tetapi juga dapat diproses sesuai dengan kebutuhan Workspace tersebut.

Kenapa harus mulai dari Pengaturan?

Karena Pengaturan menjadi dasar bagi proses berikutnya. Semakin sesuai konfigurasi yang dibuat, semakin mudah pula proses pencatatan dan pengelolaan data di dalam Workspace.

Detail mengenai apa saja yang perlu diatur tentu berbeda pada setiap Workspace. Karena itu, pembahasan konfigurasi akan dijelaskan lebih lengkap pada dokumentasi masing-masing Workspace.

2. Input — Mulai isi data

Setelah konfigurasi selesai, saatnya menggunakan Workspace untuk kebutuhan sehari-hari melalui Input.

Input merupakan tempat kamu menambahkan data baru sesuai dengan aktivitas yang sedang dilakukan. Data yang kamu masukkan akan mengikuti aturan dan konfigurasi yang sebelumnya sudah ditentukan melalui Pengaturan.

Jadi, Input bukanlah langkah pertama dalam menyiapkan Workspace. Input digunakan setelah Workspace memiliki konfigurasi yang siap digunakan.

Sederhananya

Pengaturan menentukan bagaimana data bekerja, sedangkan Input digunakan untuk memasukkan datanya.

3. Edit Input — Kelola data yang sudah dibuat

Dalam penggunaan sehari-hari, tidak semua data akan selalu masuk dengan sempurna. Bisa saja ada informasi yang salah, kurang lengkap, atau perlu disesuaikan kembali.

Untuk kondisi seperti itu, tersedia Edit Input. Fitur ini digunakan untuk mengubah atau memperbaiki data yang sebelumnya sudah dibuat melalui Input.

Dengan begitu, kamu tidak perlu membuat ulang data hanya karena ada bagian yang perlu diperbaiki.

Alurnya sederhana

Tambahkan data melalui Input, kemudian gunakan Edit Input ketika data tersebut perlu diperbaiki atau diperbarui.

Mulai dari yang paling dasar

Sebelum sibuk mencatat banyak data, pastikan Workspace sudah memiliki konfigurasi yang sesuai.

Setelah itu, kamu bisa mulai menjalankan aktivitas sehari-hari melalui Input. Jika ada yang perlu diperbaiki, Edit Input akan membantu menjaga data tetap sesuai.

Pengaturan → Input → Edit Input

Catatan

Bagian ini hanya memberikan gambaran umum mengenai hubungan antara Pengaturan, Input, dan Edit Input. Setiap Workspace memiliki aturan dan konfigurasi yang berbeda, sehingga detail Pengaturan akan dibahas pada dokumentasi masing-masing Workspace.

Selanjutnya apa?

Setelah memahami alur Pengaturan dan Input, kamu bisa mulai mempelajari fitur pada Workspace yang ingin digunakan.

Berikutnya → Tabungan

Pelajari cara mengatur dan menggunakan Workspace Tabungan.
